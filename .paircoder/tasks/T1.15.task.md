# Objective

MediaNotificationListener service

# Description

Implement `MediaNotificationListener` per spec section 9.3. Extends `NotificationListenerService`. On `onNotificationPosted`, filter for notifications with a `MediaSession.Token`. Build a `MediaController` from the token, register a `Callback` for metadata + playback-state changes, and forward the changes into `MediaRepository`. Handle `onListenerConnected` / `onListenerDisconnected` to reset state.

_From the engage backlog: Phase 4 — Media player._
