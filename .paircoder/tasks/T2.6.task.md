# Add API 23-specific crash barrier in App.onCreate()

Add a defensive `Thread.setDefaultUncaughtExceptionHandler` in `App.onCreate()` that on API 23 specifically catches `NoSuchMethodError` and `NoClassDefFoundError` and shows a user-visible toast + log before the process dies. This is a safety net for any future regressions.

## Implementation

In `App.kt` (debug builds only or behind a flag), register a default exception handler that:
1. Logs the full stack trace via Timber
2. On API 23, intercepts `NoSuchMethodError`/`NoClassDefFoundError` specifically
3. Shows a Toast with a brief message ("App crashed — compatibility issue")
4. Re-throws to let the process die normally (Android will restart the activity)

## Acceptance Criteria

- [x] Uncaught exceptions on API 23 are logged before the process dies
- [x] Toast is visible to the user (helps debugging in the car)
- [x] No performance impact on normal execution path
- [x] Disabled in release builds or controlled by BuildConfig flag
