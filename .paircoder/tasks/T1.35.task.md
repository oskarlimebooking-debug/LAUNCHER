# Unit tests for repos and recorders

Write unit-test coverage to ≥80% (project coverage_target) for `MediaRepository`, `WeatherRepository`, `LocationRepository`, `TripRepository`, `TripRecorder`, `SpeedFilter`, and util extensions. Use JUnit 4, MockK, Turbine for `Flow` testing, OkHttp `MockWebServer` for HTTP, and Room's in-memory DB.

# Acceptance Criteria

- [ ] `./gradlew :app:testStandardDebugUnitTest jacocoTestReport` produces a coverage report ≥80%
- [ ] Each repo has at least 5 unit tests covering happy path, failure path, edge cases
- [ ] `TripRecorder` state-machine tests use property-based testing (kotest-property or similar)
- [ ] Tests run in under 60 s total
- [ ] No flaky tests across 5 consecutive runs
