# App rail drag-to-reorder

Add `ItemTouchHelper`-based drag-to-reorder to the pinned app rail and to the main grid. Persist the new order to `SettingsStore.pinnedApps` and `SettingsStore.gridOrder`. Long-press initiates drag; release commits.

# Acceptance Criteria

- [x] Long-press initiates drag with a haptic + visual lift
- [x] Drop at a new index reorders the list and persists
- [x] Drag is disabled in normal scroll mode
- [x] Order survives app restart
- [x] No crashes when dragging outside the RecyclerView bounds
