# EmbedFragment integration with HomeFragment

Wire `EmbedFragment` into the right-panel ViewPager from T1.8. Settings exposes a list of "embeddable" apps (the user picks which app to embed). Default is the system Maps app. Page indicator shows the selected app's icon.

# Acceptance Criteria

- [x] User can pick an app to embed from a list of installed apps
- [x] Selected app launches into the virtual display when the embed page is visible
- [x] App is paused (no CPU work) when the embed page is hidden
- [x] Switching the embedded app does not crash (clean teardown)
- [x] Standard-flavor build shows an "Upgrade to system flavor" placeholder
