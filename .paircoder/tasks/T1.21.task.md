# WeatherWorker periodic refresh

Implement `WeatherWorker.kt` per spec section 10.5. WorkManager periodic worker scheduled every 15 minutes when network is available. Calls `WeatherRepository.fetch` and stores the latest snapshot in a `MutableStateFlow` exposed via `WeatherRepository.snapshot`. Respects OWM free-tier limits (96 calls/day at 15-min cadence — well under 1000/day).

# Acceptance Criteria

- [x] Worker runs every 15 min when on Wi-Fi or cellular (verified via `WorkManager.getWorkInfosByTag`)
- [x] Worker is rescheduled on `BOOT_COMPLETED`
- [x] Worker yields `Result.retry` on transient failures (network), `Result.success` otherwise
- [x] Last successful snapshot is persisted to `SharedPreferences` so the tile shows stale data after reboot
- [x] No crash when the OWM API key is empty (worker logs and returns `Result.failure`)
