# Objective

SpeedometerView custom drawing

# Description

Implement `SpeedometerView` per spec section 11.3. Custom `View` drawing a circular gauge with current speed numeric, max-speed tick, and a colored arc (green→yellow→red transition above `speedThresholdKmh` from settings). All drawing uses `Paint` + `Canvas` directly (no Compose). Animates transitions over 250 ms using `ValueAnimator`. Handles `onSizeChanged` for dynamic sizing on the 1024×600 panel.
