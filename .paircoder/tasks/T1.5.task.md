# Application icon and adaptive icon fallback

Provide a launcher icon for `mipmap-*` densities. Since target HU is mdpi/hdpi (1024×600), focus on those. Provide a vector drawable `ic_launcher_vector.xml` and rasterized PNGs for mdpi/hdpi/xhdpi. Provide an adaptive-icon variant in `mipmap-anydpi-v26/` (no-op on API 23 but future-proof).

# Acceptance Criteria

- [x] Icon renders correctly in the standard launcher app drawer on a 1024×600 device
- [x] Adaptive-icon XML at `mipmap-anydpi-v26/ic_launcher.xml` references a `foreground` and `background` drawable
- [x] Round icon variant (`ic_launcher_round`) is also provided
- [x] No reference to PNGs >256 KB total — keeps APK small for slow eMMC
