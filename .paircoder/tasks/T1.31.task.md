# SettingsStore SharedPreferences wrapper

Implement `SettingsStore.kt` per spec section 14.2. Wraps `SharedPreferences` with typed property delegates for: `speedUnit` (METRIC/IMPERIAL), `tempUnit`, `panelRatio` (Float 0.3–0.5), `gridColumns` (Int 3–5), `tripStartSpeedKmh` (Int), `pinnedApps` (List<String> via JSON), `mapApp`, `voiceApp`, `weatherLat/lon` (Float?), `firstRunDone` (Bool). Each property exposes a `Flow` for reactive UI.

# Acceptance Criteria

- [x] All properties round-trip correctly (write → restart app → read same value)
- [x] `pinnedApps` JSON-encodes/decodes safely with Moshi
- [x] Each property exposes a `Flow<T>` that emits on change
- [x] No `apply()` on the main thread (uses `commit` in coroutines or apply in non-blocking flow)
- [x] Unit tests cover defaults, overrides, and serialization for each property
