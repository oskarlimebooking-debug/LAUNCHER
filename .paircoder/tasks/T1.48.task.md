# Audio focus passthrough

When an embedded app requests audio focus, route the request to the system `AudioManager` so the launcher's media tile reflects it. Use `AudioFocusRequest` (or pre-O equivalent) with `AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK`.

# Acceptance Criteria

- [x] Embedded Maps app's voice prompts ducks Spotify (verified manually)
- [x] Launcher's media tile updates `isPlaying = false` during the duck
- [x] Focus is released cleanly when the embedded app finishes (Spotify resumes)
- [x] No audio leaks (verified with `adb shell dumpsys audio`)
- [x] Works with Spotify, YouTube Music, and stock Music app
