# TripRepository

Implement `TripRepository.kt` exposing `Flow<List<TripEntity>>` of recent trips (last 30 days), `getPoints(tripId): Flow<List<TripPoint>>`, `delete(tripId): suspend`, and `activeTrip: StateFlow<TripEntity?>` published by the recorder.

# Acceptance Criteria

- [x] `recentTrips` flow updates within 100 ms of a new trip being inserted
- [x] `activeTrip` reflects the recorder's state (null when idle, populated when recording)
- [x] Delete operation also removes associated points (foreign key cascade)
- [x] Repository is unit-tested against an in-memory Room DB
- [x] No coroutine leaks (tests pass under `runTest` with no pending jobs)
