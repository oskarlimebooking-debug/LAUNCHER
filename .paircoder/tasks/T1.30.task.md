# Pinned app rail integration

Add a horizontal "rail" of pinned apps along the bottom of the right panel when the AppGrid page is active. Pinned apps are persisted in `SettingsStore.pinnedApps: List<String>` (package names). Rail tile is half the size of grid tile.

# Acceptance Criteria

- [x] Rail shows up to 8 pinned apps
- [x] Tapping a rail tile launches the app
- [x] "Pin to rail" long-press action adds an app to the rail (max 8; older entries shift out)
- [x] Rail persists across launches
- [x] Removing a pinned app via long-press menu is supported
