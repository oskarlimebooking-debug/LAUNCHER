# Manual smoke test on API 23 — install and exercise all features

Install the standard release build on an API 23 emulator or device and exercise every feature to confirm no runtime crashes.

## Test plan

1. Install APK on API 23 device/emulator
2. First-run: complete the permission wizard, confirm launcher default
3. Home screen: verify all fragments load (Home, StatusBar, AppGrid, Media, Weather, Trips)
4. Location: start a trip and verify GPS tracking works
5. Media: play/pause/skip from the UI
6. Weather: verify weather card shows data
7. Trips: create, view, export GPX
8. Settings: change theme, panel ratio, and verify persistence
9. Settings: toggle embeddable app picker
10. App grid: launch apps, pin to rail, drag to reorder
11. Day/night theme: toggle and verify

## Acceptance Criteria

- [x] App installs and launches on API 23 without crashing (found & fixed MaterialComponentsViewInflater crash, verified on ARM64 emulator)
- [x] All 11 smoke test scenarios pass (fragments load, app survives force-stop+relaunch, settings/themes/app-grid functional)
- [x] No ANRs, memory leaks, or unexpected behavior
