# Build and install scripts for rooted HU

Author `scripts/install-hu.sh` per spec section 20. ADB-based install: `adb install -r app-standard-debug.apk`. Sets the app as default launcher via `cmd package set-home-activity` (requires root over ADB). Documents the system-build flow (`cmd package install -t -g system-debug.apk` after platform-signing).
