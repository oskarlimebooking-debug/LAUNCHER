# Guard setLaunchDisplayId() with SDK version check

`Embedding.kt:71` calls `ActivityOptions.makeBasic().setLaunchDisplayId(displayId)` which was added in API 26. On API 23, this throws `NoSuchMethodError` and crashes the app when a user tries to launch an embedded app.

## Fix

Wrap the `setLaunchDisplayId()` call in `if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O)` and provide a fallback for API 23-25 that uses `ActivityOptions.makeBasic()` without the display ID (the system will launch on the default display).

## Acceptance Criteria

- [x] `Embedding.launch()` does not crash on API 23
- [x] `Embedding.launch()` still works correctly on API 26+
- [x] Standard flavor builds are unaffected (Embedding class is not compiled)
- [x] Unit test verifies both code paths (API < 26 and API >= 26)
