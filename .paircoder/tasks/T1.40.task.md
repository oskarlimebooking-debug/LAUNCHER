# GPX export per trip

Implement `GpxExporter.kt`. Converts `TripEntity` + `List<TripPoint>` into a GPX 1.1 XML file written to `Downloads/RetroLauncher/trip-{id}.gpx`. Uses `Xml.newSerializer()` (no third-party XML lib). Trip detail screen has an "Export GPX" button.

# Acceptance Criteria

- [x] Exported GPX validates against the GPX 1.1 schema (verified with `xmllint`)
- [x] Track points include `<time>` ISO-8601 timestamps and `<speed>` in m/s
- [x] File is written to a `MediaStore`-visible location
- [x] `GpxExporter` has unit tests that snapshot the output XML for a 10-point trip
- [x] Failure to write (no storage permission) shows a snackbar, not a crash

# Notes

- `GpxXml` (pure) + `GpxExporter` (Context-bound) split keeps the serializer JVM-testable
  via Robolectric while isolating the MediaStore/Downloads IO branch.
- Speed lives inside `<extensions>` using Garmin's `TrackPointExtension v1` namespace —
  GPX 1.1's `extensionsType` accepts `##other`-namespaced elements, so the document
  still validates against the topografix schema (verified with `xmllint --schema` against
  https://www.topografix.com/GPX/1/1/gpx.xsd → "validates").
- Pre-Q path uses `Environment.DIRECTORY_DOWNLOADS/RetroLauncher/` + `MediaScannerConnection.scanFile`
  to make the file visible. Q+ path uses `MediaStore.Downloads` with `RELATIVE_PATH`.
- Snackbar covers `PermissionDenied` (caught `SecurityException`) and `IoFailure` branches.
