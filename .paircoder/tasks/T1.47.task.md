# Touch-event forwarding via root

Forward touch events from the `TextureView` in `EmbedFragment` to the embedded virtual display. Uses `IInputManager.injectInputEvent` (hidden API). Translates `MotionEvent` coordinates from the texture's local space to virtual-display space.

# Acceptance Criteria

- [x] Tapping a button in the embedded Maps app activates it correctly
- [x] Multi-touch (pinch zoom) forwards both pointers
- [x] Coordinate translation is exact within ±1 px
- [x] Long-press is honored (not synthesized as multiple taps)
- [x] Event injection uses `INJECT_INPUT_EVENT_MODE_ASYNC` to avoid blocking the UI thread
