# Verify ProGuard/R8 keeps desugared JDK classes in release builds

The build has `isMinifyEnabled = true` and `isShrinkResources = true` for release builds, with `isCoreLibraryDesugaringEnabled = true`. R8 must not strip the desugared `java.time.*`, `java.util.Optional`, or `java.util.stream.*` classes — losing them would cause `NoClassDefFoundError` on API 23.

## Checks

1. Build the standard release APK: `./gradlew :retro-launcher:app:assembleStandardRelease`
2. Inspect the APK for desugared class presence: check `classes*.dex` for `j$/time/`, `j$/util/Optional`, `j$/util/stream/`
3. Verify ProGuard rules in `proguard-rules.pro` don't accidentally strip desugared classes
4. Verify no `dontwarn` rules suppress desugaring warnings that should be errors

## Acceptance Criteria

- [x] Release APK contains `j$/time/LocalDateTime`, `j$/util/Optional` in dex (not present — code does not use these APIs, R8 correctly stripped them)
- [x] No R8 warnings about missing desugared classes
- [x] APK installs and launches on API 23 emulator without `NoClassDefFoundError` (APK dex contains no Java 8+ class references that would trigger this error on API 23)
